## List of Programs

### Program 1: Basic Data Types

**Description:**
This program demonstrates the use of basic C++ data types such as `int`, `char`, and `float` by storing and displaying a student's roll number, grade, and fee amount.

### Program 2: If-Else

**Description:**
This program demonstrates the use of an `if-else` selection statement to check whether a student's marks meet the passing criteria and display either "Pass" or "Fail".

### Program 3: Loop and Array

**Description:**
This program demonstrates the use of an array and a `for` loop to store and display the marks of five students.

### Program 4: Functions

**Description:**
This program demonstrates the use of a function to perform addition of two numbers. It includes a function prototype, function call, parameters, and return value.

### Program 5: Class and Object

**Description:**
This program demonstrates the concepts of class and object by creating a `Student` class with student details and a member function to display the information.

### Program 6: Constructor and Destructor

**Description:**
This program demonstrates constructors and destructors in C++. The constructor is executed when an object is created, while the destructor is executed when the object is destroyed.

### Program 7: Static Member

**Description:**
This program demonstrates the use of a static data member to count the number of objects created from a class.

### Program 8: Inline and Friend Function

**Description:**
This program demonstrates the use of an inline member function and a friend function to access and display private data of a class.
